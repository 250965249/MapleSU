# patch-engine/

Native kernel analysis and the Lite patch-plan path. The Manager's Gradle build compiles it with CMake and the NDK (`CMakeLists.txt`) into `maplesu-kernel-analyze` and `maplesu-kernel-patch`; `maplesu-native-tests` is the host test target.

| Path | Content | Origin |
| --- | --- | --- |
| `src/` | The analysis and patch front ends, `patch_plan` (plan generation) and `patch_safety` (checks on patch locations and original bytes) | MapleSU |
| `assets/releases/` | Per-kernel release assets: symbol offsets and IR specs for the supported kernel releases | Generated by [`tools/ir-gen/`](../tools/README.md) |
| `tests/` | `core_tests.cpp` | MapleSU |
| `upstream/`, `upstream-sources.cmake` | The pinned patch core and its exact compile-unit list | Third party, pinned; origin and distribution status in [Credits](../CREDITS.md) |

## Rules

- Change behavior in `src/`. Never edit `upstream/` in place; a new patch-core version is a new pinned input with its record, as described in [Native dependencies](../docs/NATIVE_DEPENDENCIES.md).
- The Manager reaches this engine through `patching/LiteBootPatcher.kt`, which validates the input, rebuilds the image and checks the resulting kernel. The engine never opens device partitions.
